# VedaUDFClaiming
ILIAS user plugin. Provides custom user data fields, required for https://github.com/leifos-gmbh/VedaConnector

**Minimum ILIAS Version:**
9.0

**Maximum ILIAS Version:**
9.99

### Quick Installation Guide
Navigate to ILIAS root directory:
```shell
cd <ILIAS_ROOT>
```
Create folder structure:
```shell
mkdir -p Customizing/global/plugins/Services/User/UDFClaiming
```
Navigate to plugin directory:
```shell
cd Customizing/global/plugins/Services/User/UDFClaiming
```
Clone plugin from github:
```shell
git clone -b 9 https://github.com/leifos-gmbh/VedaUDFClaiming.git
```
Install and Activate it in the ILIAS Administration - Plugins.
